# 库巴变变变

两张游戏卡联机、父子一起闯关的 ARPG:地图上自己走,分叉口选路;路上打怪、精英、休息、宝箱,最后打发条铁皮熊。
也能一个人玩。三个键:● 点三连击、按住蓄力斩(旁边有晕的怪:吞掉变身;队友倒了:拉起来);▼ 翻滚(怪出手前
一瞬间翻 = 完美闪避)、按住翻滚完举盾(刚举起挨打 = 弹反);▼ 后马上 ● 技能;▲ 大招;满 3 格 ▼ 后马上 ▲ 超必杀。
两个人:队友打飞的怪马上 ● 接力,一个人 ▲ 后 0.8 秒内队友也 ▲ 合体大招。

- 规则:`src/morph_battle.c`(一场战斗)、`src/morph_run.c`(地图和一趟冒险),纯 C;两张卡:`src/morph_net.c`
  (两边各跑一份,只传按键,延迟锁步);画面 `src/morph_gfx.c`;像素画 `art/*.txt` → `tools/gen_art.py`。
- 测试:`make -C tests`(乱按跑整趟、规则单测、假链路两人打整趟);`tests/sim_play.py`、`tests/sim_duo.py`
  (外壳的桌面模拟器,一个人 / 两个人)。玩法原型在 `proto/`(网页,不进游戏)。
