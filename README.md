# 库巴变变变

两张游戏卡联机、父子一起闯关的 ARPG,四关:玩具工厂(发条铁皮熊)、冰淇淋冷库(冰淇淋大王)、电池发电站(发电大魔像)、
玩具魔王城(玩具魔王)。营地里选关、用打怪攒的零件升级(血量、拳头、大招、开局能量),存档在卡上;打通一关开下一关。
每关地图上自己走,分叉口选路;路上打怪(往后有第二波)、精英、休息、宝箱,最后打 Boss。也能一个人玩。
三个键:● 点三连击、按住蓄力斩(旁边有晕的怪:吞掉变身;队友倒了:拉起来);▼ 翻滚(怪出手前一瞬间翻 = 完美闪避)、
按住翻滚完举盾(刚举起挨打 = 弹反,雪球能弹回去);▼ 后马上 ● 技能;▲ 大招;满 3 格 ▼ 后马上 ▲ 超必杀。
变身六种:普通、冰淇淋、电池、弹簧、磁铁、火箭,各有技能、大招、超必杀。两个人:队友打飞的怪马上 ● 接力,一个人 ▲ 后
0.8 秒内队友也 ▲ 合体大招;冰淇淋大王正面有冰盾、轮流盯一个人(另一个打背后),会把人冻进冰块(队友打碎);
发电大魔像要两边线圈 3 秒内一起打坏才不无敌;玩具魔王三段。

- 规则:`src/morph_battle.c`(一场战斗)、`src/morph_run.c`(营地、地图、一关),纯 C;两张卡:`src/morph_net.c`
  (两边各跑一份,只传按键,延迟锁步;开局互相交存档);画面 `src/morph_gfx.c`;像素画 `art/*.txt` → `tools/gen_art.py`。
- 测试:`make -C tests`(规则单测;乱按的 / 会玩的机器人每关打 30 趟看通关率;假链路两人打整关);`tests/sim_play.py`
  (一个人,`--chapter N --boss` 直奔第 N 关 Boss)、`tests/sim_duo.py`(两个模拟器联机)。玩法原型在 `proto/`(网页,不进游戏)。
